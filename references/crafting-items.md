# 按作用找材料

本表索引状态变化；实际部位效果和条件以查询返回的独立说明为准。

| 状态变化 | 操作/材料类别 | 关键区分 |
|---|---|---|
| 增加随机词 | Transmutation / Augmentation / Regal / Exalted | 输入稀有度、是否升级、旧词是否保留、容量与等级下限 |
| 删后生成 | Chaos / Perfect与Corrupted Essence / Alloy | 删除选择器、生成来源和删后槽位/互斥分别确定 |
| 删除 | Annulment、相应预兆 | 可删集合、侧别、数量、来源与等级选择器 |
| 固定 | Fracturing Orb | 门槛计数和合格抽选集合不同；仍计槽位并限制改变 |
| 保证指定部位效果 | Essence / Alloy | 品阶×物品类别对应的具体效果；crafted当前占用与同组资格 |
| 改写一次操作 | Omen | 触发通货/阶段、对象、删除/新增端、数量、权重、揭示或终态 |
| 品质/标签 | Whetstone / Etcher / Scrap / Catalyst | 对象、类型、数值、可添加上限和消耗；不天然改变生成权重 |
| 数值 | Divine、圣化、腐化、Vaal Siphoner | 重骰、按当前值乘倍率、降阶或改善是不同变换 |
| 属性转换 | Resistance Flux / of Aldur Rune | 抗性词缀与武器元素词缀转换不同，后者有永久绑定条件 |
| 容量 | 特殊底材 / Astrid's Creativity / Serle's Triumph | ordinary显式槽、crafted、总数或插槽容量分别变化 |
| 孔位 | Artificer's Orb / Jeweller's Orbs / Cadigan's Epiphany | 增幅孔、技能辅助孔、珠宝孔不同；Cadigan销毁现有增幅孔以建珠宝孔 |
| 镶嵌 | Rune / Soul Core / Idol / Ancient Augment | 部位效果、数量、Socket-bound、Bonded和覆盖损失 |
| 生成池资格 | Thrud's Might、Uhtred's Sidereus、Kolr's Hunt等 | 解锁不是直接获得词；绑定与生成标签另记 |
| 亵渎 | Jawbone / Rib / Collarbone / Cranium / Vertebrae | 适用类别、等级、当前亵渎占用、未揭示状态、特殊池和满词行为 |
| 特殊后处理 | Vaal Infuser / Architect's Orb / Sacrifice Orb等 | 各自腐化对象的明确适用性、数值变化、删词或毁坏风险；不适用于推断圣化后可修改 |
| 回收/生产 | Orb of Extraction / Aldur's Legacy / Core Destabiliser | 产物与输入销毁、不可回收绑定材料、随机损坏分别计费 |
| 底材生产 | Runeforging / Genesis / Wombgift | 具体输入、输出、ilvl和新底材属性，不等于现物无损换底材 |

已核实作用直接复用；具体效果缺项或版本差异再定点查源。不可逆条件见 `critical-rules.md`，原理见 `state-and-planning.md`、`crafting-logic.md`；不按本表顺序执行。
