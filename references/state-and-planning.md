# 装备状态与基础机制

## 状态由哪些独立量组成

| 量 | 含义与作用 |
|---|---|
| 底材、物品类别与 ilvl | 底材固有、可用插槽、生成池和阶级资格；换底材与在现物上操作是不同动作 |
| rarity | normal / magic / rare / unique，决定可用通货及通常容量 |
| 显式词缀 | 每条的来源、侧别、家族/排斥组、mod level、Tier、数值、可删/可变更/可分裂性 |
| 容量与占用 | prefix、suffix、总显式、crafted、desecrated 各自计数，特殊底材/增幅器可改动其中一项 |
| 品质 | 类型、已存数值、当前可添加上限、适用标签与数值结算层；三者不互相代替 |
| 插槽 | 装备 Augment Socket、技能辅助孔、珠宝孔分别计数；所装材料、Socket-bound、数量限制、Bonded条件另记 |
| 特殊状态 | corrupted、sanctified、mirrored、未揭示词缀、标记、临时解锁、预见结果 |
| 用户资产与目标 | 必须保留的词/底材、允许承担的损失、硬需求与可接受区间；已花成本与未来新增投入分开 |

未知状态保持未知。词缀显示多行未必是多条，特殊来源也不等于额外槽位。

## 稀有度、容量与词缀来源

普通魔法装备最多一前一后；普通稀有装备最多三前三后。部分物品类别或底材有不同规则，以其容量覆盖默认值。增幅新增而不删除，魔法装备已有一侧时，另一侧空位限制新增侧。普通剥离不改变稀有度；零词魔法与零词稀有仍有不同的可用通货。

富豪保留已有词、增加一词并升稀有；点金产生四条随机词，不能假定保留蓝装已有词。稀有度升级通常没有普通通货逆转。因而中间稀有度、词数和占位都是决策变量，不能从最终稀有度直接决定操作起点。

0.5 默认同时最多一条 crafted、一条 desecrated。精华/合金的保证词属于 crafted，亵渎单独计数；它们仍占对应前/后缀位置。当前占用不是历史使用次数。固有、显式、附魔、插槽提供效果和物品授予技能分别核对。

来源：[Item Rarity](https://poe2db.tw/us/Item_Rarity)、[Currency](https://poe2db.tw/us/Currency)、[GGG 0.5.0](https://www.pathofexile.com/forum/view-thread/3932540)。

## 等级、类型与数值

- ilvl 决定可出现哪些阶级；mod level 用于通货最低等级及最低等级删除。装备需求等级、Tier编号和mod level是不同字段。
- T1指目标来源/部位的完整阶级中的最高阶，不是当前低ilvl恰好能出的最高阶，也不是查询显示的最后一行。
- 家族/组用于互斥；Attack、Fire等标签用于品质或权重，标签不是互斥组。Minimum Modifier Level 的“整类不排空”规则中的modifier type与ModFamilyList的关系仍有证据边界。
- 阶级与掷点分别改变。神圣重骰数值通常不改变阶级、词缀身份和侧别；其作用被预兆改写时按新范围计算。分裂词仍占槽，通常不能移除或改动，包括数值。
- 词缀权重应来自对应部位/来源的数据。占位、互斥和删除会改变后续池；普通池、保证池与揭示池各有选择机制。

## 删除、生成与修饰

删除集合由具体操作、可删性、侧别或等级选择器共同确定。分裂词退出普通可删集合；定向删除只筛选一侧，不指定该侧哪条。最低等级在实际可删集合内比较，同级随机规则需有依据。

普通C先删一词再按剩余状态加一词，保留稀有度且通常不改变总词数。它不会因删了某侧便自动保证同侧新增；满位也要在删除后重算。多次新增或删除需要逐次更新池，不能把第二次当独立的原状态抽取。操作遇到空集合时是拒绝、仅执行其他阶段还是消耗而无变化，要由该操作机制确定，不能从集合为空直接推定整次操作结果。

预兆改写明确的触发操作及阶段，可改变删除端、生成侧、数量、类型、权重、揭示选项或终态。已知触发关系不等于所有修饰都能联合使用；部位条件、同次触发与消费顺序仍属于各自作用。具体关系随道具查询返回。

## 数值结算与特殊状态

品质按物品类型或标签作用：武术武器物理伤害；护甲的Armour/Evasion/ES/Runic Ward；药剂回复量；护符持续时间；技能宝石或授予技能的装备按其技能品质效果。首饰催化品质影响匹配词缀数值，权重改动需要对应操作；更换类型或消耗后按当时条件恢复。局部与全局增益、flat/increased/more和显式/插槽效果倍率分别结算。

0.5圣化和腐化的某个超界数值结果以当前词缀数值乘倍率，不先重掷普通范围；该结果依赖输入值。普通Divine、圣化和腐化不是同一种数值变换。

神圣预兆（Omen of Sanctification）配合Divine使稀有装备圣化。同一件只能圣化一次，**圣化后的装备无法再改变**；数值、品质、词缀与插槽处理在圣化前完成。结果未达目标是不可继续修改的终态，不能靠再次神圣或圣化重试。该终态限制由用户确认当前0.5语境。腐化物品有明确适用的专用操作，不能把这些例外外推到圣化；镜像也按其独立限制判断。

Bonded效果需要Shaman的Wisdom of the Maji，并非安装即对所有角色生效。Socket-bound的增幅器不能移除、替换或抽取；非绑定增幅器的覆盖与返还规则独立。装备增幅孔、自带技能辅助孔和珠宝孔不是同一容量。
