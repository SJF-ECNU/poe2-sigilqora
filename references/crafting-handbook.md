# 通用做装知识合集

适用语境：PoE2 0.5；独立道具效果、部位与版本以查询记录为准。这是可组合的手段库，不是某件装备的制作顺序。A、B表示任意目标词，是否属于普通池、能否共存及可否分裂分别判断。

## 从哪里开始想

把目标拆成值得保留的中间状态，例如“一个目标词”“一个分裂词”“同侧两条目标词”“已处理品质的胚”。到达每个状态都可以自制或购买；之后的操作从这个状态重新推导。少词、魔法稀有度、不可删词、临时来源和占位各自可能改变下一步的成本。

| 当前需要 | 可用知识 |
|---|---|
| 找划算的起点，避免高投入自制 | §1 买胚、自制与半成品 |
| 先得到一条普通目标词 | §2 魔法阶段；§3 通货品阶；§4 标签催化 |
| 把目标词变成后续可保留的锚点 | §5 分裂；§6 亵渎垫锁 |
| 已有分裂词，再找下一条 | §7 锁+C；§8 少词清理 |
| 限定新增或保护已完成一侧 | §9 侧别、占位与互斥 |
| 保证词、临时品质或其他工具词 | §10 精华/合金；§11 临时来源；§12 削低等级词 |
| 特殊池、属性转换、终局数值 | §13 亵渎；§14 转换与解锁；§15 收尾 |
| 在候选之间算账、决定何时停 | §16 成本与停止条件 |

## 1. 买胚是制作动作的一部分

交易可直接取得白底、单条好词蓝装、带目标词的黄装、已有分裂词的胚、完成一侧或接近目标的半成品。普通材料报价不能替代这些装备的挂单价。高投入工序前，购买同等中间状态往往是值得比较的候选；不需要先把整套从零流程做完才考虑购买。

检查的是后续可用性：底材、ilvl、目标真实阶级/基础数值、分裂的是哪条、其他词能否清理、互斥组、品质类型/上限来源、crafted/亵渎占用、腐化/圣化/镜像和绑定孔。便宜的错误分裂词、低ilvl、不可继续操作或清理会毁目标的胚，不能当等价输入。

对同一中间目标：

- 自制：取得输入 + 取词 + 凑前提 + 赌锁/失败重做 − 可实现残值。
- 买胚：实际买价 + 清理/修正 + 从其实际状态继续的费用。

即使已有一件物品，也能比较“继续改现物”和“卖现物、换更合适胚”；已花的钱与当前可出售价值分开。缺挂单时给可接受买价上限，例如 `最高买价 = 替代路线剩余费用 − 买胚后的清理与续做费用`，而不是宣称市场一定更便宜。用户指定现物必须保留时，按该约束规划。

## 2. 魔法阶段取词，再升稀有

普通魔法装备一前一后、最多两词。最终要稀有六词，并不要求第一条词也在稀有阶段取得。蜕变用于白装产生一词；增幅用于有空位的魔法装。零词魔法仍是魔法，不能再次当白装蜕变。富豪保留原词再升稀有并添一词；点金重新生成四词，不能用来保留蓝装锚点。

**增幅+剥离的循环：**从魔法状态添加随机词，不满意则剥离，再按实际留下的词继续。若仅一条词且可删，剥离可回到零词魔法；若已有一条后缀作占位，增幅只能生成前缀。此时失败后普通剥离也可能删掉占位后缀，恢复分支和成本与“必删垃圾”不同。目标是后缀时对称推导。

可比较零词蓝装反复取词、保留对侧占位、买单条目标蓝装、直接稀有取词等起点。完美增幅的最低词缀等级为70，完美崇高为50；不能把稀有阶段的筛池直接套到魔法通货。ilvl必须允许使用该品阶及生成完整词池的目标T1；低ilvl当前最高阶不等于真正T1。

成功得到所需单词后，可以先升稀有再凑分裂前提，也可以继续比较其他中间目标。升稀有会改变后续可用通货，通常不能用普通通货退回魔法阶段，故升级时机本身有价值。

## 3. 通货品阶改变的是生成条件

普通/高级/完美不是一律越高越省。最低词缀等级会改变可生成阶级，且有“具体类型不能被整类排空”的例外；最高阶等级低于门槛的词不能直接算成消失。已有词也不会因新增用了完美通货而自动升阶。

比较同一中间目标的命中率、通货价、失败清理及恢复，不只比较单次概率。便宜的普通取词、昂贵的强筛选取词、其他稀有度取词和买胚都可能胜出。词池按全阶级确认目标，再按当前ilvl/组/品阶筛选。

C也按品阶分别比较：高级C的最低新增词缀等级为35、完美C为50。过滤低等级阶级可能减少竞争权重、降低期望次数；仍须应用整类不排空例外，不能直接删除整个低等级家族。门槛作用于新增阶段，不改变已有词的删除资格；每个删除分支之后按该品阶重新建池。较高单价是否被概率改善抵消，连同误删、恢复和成功后续做费用一起判断。普通C单价低、已有分裂锚点、或用户提出先C，都不能单独证明C路线更便宜。

## 4. 催化品质既可增数值，也可成为增权输入

首饰催化品质本身提升匹配标签的词缀数值；`Omen of Catalysing Exaltation`才把对应品质转为下一次崇高的权重影响，并消耗全部催化品质。标签内干扰词也一起增权，不是保底目标或只提高目标T1。

由目标标签可推导“匹配催化品质 + 催化崇高预兆 + 某品阶崇高”的候选；需要定侧时另核对适用修饰及联合触发。计算包括补品质、预兆、通货、失败后的清理与再补；品质增量按具体催化剂和输入物品计算。最终数值用的品质类型与取词阶段增权类型可以不同，但切换/恢复有实际代价。

倍率未知时可用 `p(k)=kT/(kF+N)`，T为标签内目标权重、F为标签内全部权重、N为其余权重。比较达到什么倍率或材料价格时更合算，不把社区估计写成固定倍数。见 `crafting-logic.md`。

## 5. 如何分裂一条词

这里“锁”指Fracturing Orb把一条合格词永久固定。不是锁整侧，不是指定目标，也不是预见结果。分裂词仍占位置；之后的C、普通剥离等不能移除它，神圣也不能重掷其基础数值。需要某个基础掷点时，应把洗值或购买该数值计入锁前费用；品质改变显示值与重掷基础值是不同事情。

取得目标A可以靠购买或自行生成。要使用分裂石，物品须为满足条件的稀有物品，至少四条显式词；凑数可由保留目标后的合法追加、升稀有或特殊来源产生。凑数用哪些词，决定了合格候选集合，也会影响成功后的清理。已有分裂的物品不能再用分裂石，锁错通常不能在原件上重新赌锁。

设合格候选n条，其中锁中任意一条都能接受的有t条，等概率抽取时成功率`t/n`。总词数满足使用门槛，不等于n；候选资格与删除资格也不相同。多个可接受目标可共同算成功，但不同锁中结果的后续费用可能不同。

自制期望应包含每轮取得目标、凑数、分裂材料、失败品回收和成功后清理，不能只算“分裂石价÷命中率”。锁较难词还是较易词，要连同锁后重洗路线一起算；“永远锁最贵/最便宜”都没有通用依据。直接买正确分裂胚是另一条取得同等状态的路径。

## 6. 亵渎垫锁：数量门槛与抽取候选分开

**通用示例：三条可分裂普通词A、B、C，加一条未揭示亵渎词U。**四条显式满足分裂的数量门槛，U不参与分裂抽选，故合格集合为A、B、C。只接受A时为`1/3`，接受A或B时为`2/3`。这是特定状态的结果，不是所有装备裸用分裂石都是1/3。

构造这种状态需要该部位可用的骨头、使用等级/稀有度条件和亵渎名额，并考虑骨头加词时的容量；若加亵渎触发随机删除，不能假定原来的A、B、C都保留。垫数期间保持这里已知的**未揭示**状态，不能从“揭示了”自行推论分裂资格改变，也不能从crafted名额推论crafted词不参与分裂。

费用包括骨头、凑词、分裂失败损失和成功后的清理。需要再次亵渎时，先处理当前亵渎占用；若还要保留未锁好词，可比较光明预兆+剥离与其他可接受的清理分支。若普通可删集合已只剩可放弃的词，昂贵的来源定向删除未必必要。清理时重新数可删词，而非继续用分裂时的候选数。

这项未揭示垫锁机制在当前语境已确认，直接用于相同条件的推导；具体证据与边界见 `advanced-interactions.md`、R13。没有依据的crafted排除或额外1/2命中率，不应混入这个已知示例。

## 7. 锁+C：固定一个锚点，轮换工作词

已有分裂A后，普通删除不再伤A。C在稀有物品上删除随机可删词、再随机添加，因而可以寻找下一条普通池目标B。这里改变了后续失败状态，但是否采用仍取决于成本；C的各品阶筛池和取价见§3，也与其他取词或购买候选比较。

**少词形态：分裂A + 一条可替换工作词X。**C删除X，A保留，再按剩余容量和互斥生成新词；不是默认满六词，也没有“必须先填满”这一前提。若新词不是B，可在仍只有A和工作词的状态重复；命中B即达到局部目标，后续可以换手段。若物品只有分裂A且C需要可删对象，可用合法追加构造工作词；空删除集合时该通货的行为见具体机制，不能凭空算作免费加词。

即使A在前缀，C生成B也不自动限定前缀：还要计算删后的选侧和两侧合法池。有空位、满位、其他工作词或互斥时，概率分别变化。少词状态不能套六词的`2/5`删前概率；C也不是重洗所有非分裂词。

达到A+B后可停止C并换用适合新状态的动作；继续裸C时B才进入该操作的可能删除集合。后续可以通过删除侧修饰保护B所在侧，再处理另一侧；这会增加选择器费用，也会降低对应损失。需要在完整续做费用中比较，而非套用没有B时的操作次数。特殊池或crafted目标不能因为可锁就默认能由普通C生成。

## 8. 少词清理与恢复

删除只从实际可删集合抽取，分裂词不占普通删除的概率分母。若只剩分裂A与一条可删垃圾X，普通剥离就能删除X；若A以外同时有好词B和垃圾X，裸剥离会威胁B。方向预兆只限一侧，不指定垃圾；一侧仅有一个可删词时，它才成为该侧确定目标。

稀有装被剥到一词或零词通常仍是稀有，魔法也不因剥空变白；可用通货依旧取决于rarity。清理有时是降低后续C/删除的状态复杂度，有时反而损失有价值的占位或好词。不能把“先清空再做”当作无成本惯例。

还可比较接受低档工作词、在失败状态继续、保留半成品出售、换胚等分支。每种分支保留的资产不同，不能都记成同一个reset费用。

## 9. 定侧、占位与组阻挡

| 手段 | 实际改变 | 不随之保证的事 |
|---|---|---|
| 分裂 | 指定被随机锁中的词不可普通删除/改动 | 不保护其他同侧词 |
| 左右旋删除修饰 | 对应操作只从前/后缀删 | 不指定侧内垃圾；不自动约束新增 |
| 左右旋新增修饰 | 对应操作只在前/后缀生成 | 不保护该侧已有词，也不指定词族 |
| 填满一侧 | 无删除的新增受剩余容量限制 | 先删后加操作可能重新打开该侧 |
| 已有同组词 | 阻挡同组随机生成或材料使用 | 不保护该词免被删除，也不等于标签阻挡 |

占位的价值是改变合法池或侧别，代价是取得和最后移除。若占位词会在C/精华/合金删除阶段离开，后续池必须重建。保留同组低阶词会挡住同组高阶目标；它何时是有用阻挡、何时是必须清掉的障碍，由当前目标决定。

**同一状态的选择器示例：**前缀为分裂A、需保留B，后缀仅有可删工作词X。普通删除只排除分裂A，其余集合会因修饰改变：

| 删除操作 | 实际可删集合 | 删除B的概率 |
|---|---|---:|
| 普通剥离 | {B, X} | 1/2 |
| 右旋剥离预兆+剥离 | {X} | 0 |
| 左旋剥离预兆+剥离 | {B} | 1 |

保护前缀时，这里的右旋限定删除后缀。若后缀还含好词C，右旋的集合变为{C,X}，保护前缀仍然成立，但删除C的风险为1/2。由实际集合分别判断“保护另一侧”和“只删本侧垃圾”；选择器费是否值得，再与丢词、重建及其他候选比较。它们是同一状态的不同动作，不能以裸剥离的风险否定定侧候选。

完整一侧的保护可以来自选择器或后续操作的输入限制；PoE1的工艺台“前缀无法改变”不能凭印象搬过来。所谓“锁前”“保后”应落实到具体可用机制，不用简称代替其保护范围。

## 10. 精华/合金保证词与牺牲位

保证效果先按**部位、品阶、来源**查清。魔法升稀有的精华与稀有上先删后加的完美/腐化精华不同。合金也是先删后加部位指定crafted词，和精华共享默认crafted名额；互斥或名额可能在删除前检查，不能假定材料会先删掉阻挡者。

结晶预兆能够控制完美/腐化精华以及合金的删除侧，这个合金联动在当前0.5语境已验证。另一侧已有目标词时，可以由此推导“准备可牺牲一侧、定侧删除、保留另一侧”的候选。先确认可用名额和最终词位；牺牲侧有多个可删词时仍在它们之间抽，不能自动只删垃圾。

要比较保证词放早、放晚、被误删后重打以及购买已有保证词胚的费用。来源不能共占一个名额，不等于它们不能在不同时间先后使用；强制词可否被锁、能否被其他生成替代也分别判断。短说明只提精华，不推翻已核实的合金删除侧关系，详见 `advanced-interactions.md`。

## 11. 临时来源：取得结果后释放占用

最大品质词是**可添加上限的来源**，已存品质是另一个状态。裂隙精华的最大品质前缀可以用于提高首饰可添加上限，打好品质后移除该前缀，已存品质保留，前缀和crafted名额释放。这是中间工具词的用途，最终词位计算不包含已移除的来源。

因此品质处理不必机械放第一步。可以早做以便低成本清理，也可以在较有价值胚形成后做，减少失败胚上的品质投入；比较插入工具词、保护现词、切掉工具词及恢复的费用。之后若增权预兆消耗品质或更换类型，恢复受到**当时**上限约束；只算催化剂价会漏掉恢复上限的成本。

额外crafted容量、增幅器与池解锁也可能服务中间状态，但结果存续各有独立规则。Astrid容量覆盖后的存续有特定版本社区记录，Socket-bound却不能移除、覆盖或抽取。不能把品质保留概括成“任何临时扩容都可切掉且无后果”。

## 12. 最低等级删除：削工具词而非看Tier

Whittling+Chaos从可删集合中删除最低mod level词，然后C仍添加新词。若一个临时工具词是唯一最低等级，它可能成为可控制删除对象；若另有同等级占位，则不能当确定删除。目标T1的mod level也可能低于垃圾词，“最低等级”不等于“最差词”。

操作后新词可能回到刚打开的侧，故还要计算下一状态。用它腾出永久空位、换到另一侧或清掉crafted占用是不同中间目标，不能只看到删成功就跳到下一步。有多种清理办法时，与普通剥离、定侧剥离、C继续滚或换胚比较完整费用。

## 13. 亵渎是加词、揭示和重试三个问题

骨头按部位、等级和品阶适用，产生未揭示亵渎词；灵魂之井揭示才出现可选择的结果。定侧预兆影响对应侧，指定深渊系预兆约束对应来源，回响作用于揭示选项。各修饰的联合条件、选项抽样规则与数值阶级分别核对，不能由“池两项、展示三项”直接得出必见或75%。

当前有亵渎词会阻止再亵渎；移除后可以重新处理，不是一件一生只能用一次。光明预兆改写剥离的删除来源，用来保留其他值钱词时有意义。空位、满位时加词可能伴随删除，不能把每一次亵渎都当免费追加。

亵渎既可用于最终目标，也可作为未揭示垫数状态。两者对骨头成本、揭示、清理与后续亵渎占用的要求不同；垫锁不必付最终目标的揭示筛选投入。

## 14. 转换、解锁与特殊底材

某个效果直接取词昂贵时，还可检查是否有合法的属性转换、池解锁或底材生产方式。抗性Flux、Aldur武器元素转换、Runeforging和特殊基础容量是不同机制；按具体输入→输出查看，不能只按“火”“转换”等词联想作用。

转换可能让相邻目标成为可接受输入，但要核对阶级、数值、组、孔位及绑定后果。解锁池不等于保证生成，会增加候选也可能增加干扰；Bonded要求对应角色条件。特殊底材若改变用户指定基础，则属于不同目标版本，需要明确区别。

## 15. 数值收尾、预见与终态

神圣重掷普通数值与改Tier不同；分裂前数值、固有数值、品质加成和局部/全局结算分开。Blessed预兆可改写Divine范围。神圣预兆（Omen of Sanctification）使装备圣化，**同件只能一次，圣化后无法再改变**。0.5圣化按输入当前值乘倍率，所需洗值和其他修改在圣化前完成；结果不满意也不能再神圣或圣化重试。

Hinekora's Lock是预见下一次通货结果，**不是分裂锁词**；改变物品会失去该预见。是否值得买预见，比较它避免的实际损失和后续成本，而非只说目标贵就该用。腐化的某类超界结果也依赖当前值，但其专用操作与圣化终态分开判断；复制与绑定另有独立限制。

最终还缺词时先圣化，会失去在原件上继续制作的资格；已有圣化物品按不可修改结果评估使用价值或交易替换，不安排后续改装。腐化物品则按其明确允许的专用机制判断，不能照抄普通胚路线。具体不可逆风险保留在 `critical-rules.md`。

## 16. 如何给手段算账，何时换手段

局部目标达到后，重新计算选择，而不是把原来的动作连续点到六词完成。成功、误删好词、丢占位、消耗品质、锁错和可售半成品，是不同后继状态。总价既不是各条T1的独立期望之和，也不是最贵删词预兆价乘总次数。

失败总能回同一状态时：`E = [单次材料费 + (1-p) × 失败恢复费] / p`。赌锁每次失败需重买/重制输入，则把该输入及残值放进相应轮次；成功后清理另计。失败不能回原状态时，用 `V(s)=操作费+Σ P(s')V(s')`，只保留影响决策的状态即可。

每个候选取得的是同等中间目标，比较后续剩余费用与风险：买A胚再取B、买B胚再取A、自制后锁、直接买正确分裂胚，可能各有优势。改变起手或中间状态后，重新选择后续动作及保护方式；“旧路线剩余多少次删除”只是旧路线的性质。哪条词拿去锁与怎样取得它需要一起优化；某次价格下的胜者不成为通用顺序。缺价用变量或临界价，未知价格不是免费。

期望费用不保证预算内成功；决定继续、卖半成品或换胚时看未来增量和当前资产价值。给用户保留可执行的主方案、关键失败分支和候选取舍；无需把全部探索过程和无关道具目录放进最终答复。
